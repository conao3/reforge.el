A modern GitHub collaboration interface for Emacs, built on top of Magit.

* Overview

reforge.el provides seamless integration between Emacs and GitHub, allowing you to manage repositories, issues, and pull requests directly from your editor. It extends Magit with a dedicated transient interface for GitHub operations.

* Features

- Transient-based UI integrated with Magit
- GitHub repository browsing and management
- Async operations using promises for smooth performance
- Database-backed with closql for efficient data handling

* Requirements

- Emacs 28.1 or later
- Magit 2.90 or later
- promise.el 1.1 or later
- closql 1.0.4 or later

* Installation

** Using leaf.el

#+begin_src emacs-lisp
(leaf reforge :ensure t)
#+end_src

** Using use-package

#+begin_src emacs-lisp
(use-package reforge
  :ensure t)
#+end_src

** Manual Installation

Clone this repository and add it to your load-path:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/reforge.el")
(require 'reforge)
#+end_src

* Quick Start

Initialize reforge to add keybindings to Magit:

#+begin_src emacs-lisp
(reforge-init)
#+end_src

Once initialized, press =\= in any Magit buffer to access the reforge dispatch menu.

* Configuration

reforge.el works out of the box with sensible defaults. Customize the =reforge= group for available options:

#+begin_src emacs-lisp
M-x customize-group RET reforge RET
#+end_src
